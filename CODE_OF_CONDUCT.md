# Code of Conduct

## Our Standards

This project is a professional engineering environment. Contributors are expected to:

- Communicate with technical precision and respect
- Provide constructive, evidence-based code review
- Accept feedback on their own work professionally
- Prioritise correctness and safety over velocity — this platform interacts with live financial markets

## Unacceptable Behaviour

- Harassment, personal attacks, or discriminatory language
- Sharing credentials, API keys, or proprietary market data in issues, PRs, or discussions
- Intentional introduction of vulnerabilities or backdoors

## Enforcement

Violations may result in removal from the project. Report concerns to the project maintainers via private message or the security contact in `SECURITY.md`.
